# Remote Dev Terminal 安装说明

## 适用环境

本程序适用于 Omarchy（基于 Arch Linux），需要图形桌面、网络连接，以及能够使用 `sudo` 安装软件的账号。请将整个 `omarchy` 文件夹复制到目标电脑，保留文件夹内的所有文件。

## 安装

打开终端，进入复制后的 `omarchy` 文件夹。例如，如果它位于下载目录：

```bash
cd ~/Downloads/omarchy
```

实际路径不同时，请把上面的路径替换成实际位置。然后安装依赖并运行安装脚本：

```bash
sudo pacman -S --needed python python-gobject gtk3 vte3 openssh
chmod +x install.sh
./install.sh
```

安装脚本只为当前用户安装程序，文件位于 `${XDG_DATA_HOME:-~/.local/share}/remote-dev-terminal`，并在当前用户的应用菜单中创建 **Remote Dev Terminal** 启动项。安装后从应用菜单启动即可。

## 首次使用

1. 在左侧「主机」中添加服务器名称、地址、SSH 端口和用户名。
2. 点击主机，在「工作区」中添加远端绝对路径；也可点击「浏览远端目录」选择目录。
3. 选择当前主机的 Codex、OpenCode、Antigravity 或 Shell Agent，然后点击工作区名称直接打开终端；再次点击已打开的工作区会回到现有会话。主机、工作区和各主机的 Agent 均可添加、编辑和删除。
4. 首次连接时核对并确认服务器 SSH 指纹，按提示输入密码或密钥口令。推荐使用系统 SSH 密钥和 `ssh-agent`。

工作区默认使用标签页，最多可同时打开 8 个终端。点击右上角「平铺模式」可并排查看终端，最多 4 列、2 行；再次点击可切回标签页。点击左上角「菜单」可以收起或展开左侧管理栏。

远端服务器需安装 `tmux`，才能在网络中断后恢复终端会话；目录浏览需要远端提供 GNU `find`。Codex 和 Antigravity 配额由对应的远端命令提供，暂不可用时显示「--」。

自动回车默认关闭，可在侧栏启用并设置 1–30 秒延迟。启用后，程序会自动确认识别到的肯定选项或回车确认提示，请仅在信任远端命令时使用。

## 更新和卸载

更新时，用新版本替换整个 `omarchy` 文件夹，再在该文件夹内重新执行 `./install.sh`。配置保存在 `${XDG_CONFIG_HOME:-~/.config}/remote-dev-terminal/config.json`，更新不会删除配置。桌面版不能自动导入 Android 版的密码、密钥或会话。

如需卸载程序和应用菜单项，可在终端执行：

```bash
rm -r "${XDG_DATA_HOME:-$HOME/.local/share}/remote-dev-terminal"
rm "${XDG_DATA_HOME:-$HOME/.local/share}/applications/remote-dev-terminal.desktop"
```

上述命令保留配置文件；如不再需要配置，请自行删除 `${XDG_CONFIG_HOME:-$HOME/.config}/remote-dev-terminal`。

## 已知限制

关闭标签或退出程序后，目前不能从界面恢复旧标签；远端 tmux 会话不会自动删除。当前版本尚未在真实 Omarchy 机器和 SSH 服务器上完成端到端验证。
